# Пираты, формат 8-bit

Спрайты 16×16 генерируются из текстовых карт в `tools/pixel_sprites.py`, править там, затем
`python3 tools/pixel_sprites.py` и `Godot --headless --path thegames --import`.

Палитра, 4 цвета плюс чёрный: чёрный `#161412`, море `#2F6FB5`, тельняшка и кости `#F4EFE6`,
песок и дублон `#F2C85A`, дерево `#A85A2A`.

Слоты (спека `docs/specs/demos_catalog.md`, набор ассетов сеттинга): герой `hero_run_0..2`,
`hero_jump` (матрос); противник `enemy_0..1` (скелет); бонус `coin` (дублон); чекпоинт
`checkpoint`; финиш `flag` (флаг с черепом); земля `ground` (кромка палубы) и `ground_inner` (толща); платформа `platform`; фон `cloud_small` 16×16 и `cloud_big` 32×16.
Гонки (#48), вид сверху: транспорт `boat_0..7` (шлюпка под белым парусом, 8 направлений по
часовой от «вправо»), соперник `rival_0..7` (жёлтая под чёрным парусом), земля трассы
`race_water`, `race_water_1` (вода с бликом), обочина `race_shallow` (отмель), стена
`race_sand`, `race_sand_1` (берег, с ракушкой), препятствия `race_barrel`, `race_rock`, буй
`race_buoy`, финиш `race_finish` (шахматная полоса). У космоса и замков слотов гонок пока нет,
берутся пиратские. Остальные слоты сеттинга приходят со своими демками.
