# Концепты визуального кода

Статичные макеты 1920×1080 по `docs/STYLE.md`. Проверяют, что текст понят одинаково, а не
финальный UI. Исходник HTML плюс PNG на каждый, общие токены в `_tokens.css`, пиксельная
студия и портреты в `_pixels.js`. Шрифты системные как заглушки.

Пересобрать PNG (нужен Google Chrome):

```
sh docs/concepts/render.sh            # все
sh docs/concepts/render.sh 04-feed    # один
```

| Файл | Что проверяет |
|---|---|
| `01-constructor` | карусели поверх студии, фокус, заблокированная карточка, метка насыщения, смета |
| `01b-constructor-no-money` | то же, денег не хватает: красная строка, неактивная кнопка в фокусе |
| `02a-sprint-intro` | интро-карточка спринта: значок аспекта, глагол, подсказка первого релиза, ввод |
| `02b-sprint-fit-frame` | кадр «Подгони»: тарелка, всплывающая фигура, два трафарета, таймер, точки спринтов |
| `03a-result-ok` | результат спринта засчитан, цвет `success` |
| `03b-result-bug` | результат спринта провален, штамп бага |
| `04-feed` | лента отклика: твит, критик с пиксельным лицом, клип стримера с багом, цифры, «В демо» |
| `05a-studio-empty` | студия первого релиза без оболочки |
| `05b-studio-grown` | студия десятого релиза, карточка предложения прокачки поверх |
| `06-meta-event` | мета-вставка: пиксельный портрет, реплика, три выбора с последствиями |
| `07-flood-fill` | кадр «Залей»: сетка крупных пикселей, палитра из четырёх акцентов, счётчик заливок |

Правило из STYLE.md: расхождения правятся сначала в тексте, потом здесь.
