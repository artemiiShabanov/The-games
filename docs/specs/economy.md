# Экономика

**Status:** Draft · **Issue:** #

## Цель

Деньги делают каждый релиз ставкой: дорогая тройка и раздутая студия могут разорить, дешёвая
даёт передышку.

## Поведение

- Приход: хвост продаж всех прошлых игр, тикает в фазе студии.
- Расход: спринты (цена от тройки, списываются при старте разработки), спринт багфикса,
  содержание студии за релиз (растёт с прокачкой), покупка прокачки.
- Банкротство: в фазе студии не хватает на самый дешёвый релиз. Перед ним одна вставка спасения
  (спека меты). После неё повторное банкротство заканчивает забег без оценки.
- Стартовый капитал покрывает несколько дешёвых релизов, точное число открыто.

## Данные

- Сигналы: `money_changed(amount: int, reason: StringName)`, `bankrupt()`.
- Состояние: `Wallet` — деньги; `Upkeep` — содержание по уровню студии.
- Тюнинг: `res://resources/economy.tres` — стартовый капитал, содержание по уровням, цены
  прокачки.

## Крайние случаи и вне скоупа

- Ремейк и сиквел по цене как новая игра.
- Вне скоупа: кредиты, цена продажи, налоги, зарплаты поимённо.
