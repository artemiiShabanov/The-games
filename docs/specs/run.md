# Забег и финал

**Status:** Draft · **Issue:** #

## Цель

Забег на 1-2 часа с понятным концом и причиной начать второй: галерея своих игр.

## Поведение

- 10-14 релизов, мягкий кап, игроку сначала неизвестен. Как ощущается приближение: открыто.
- Концовки с оценкой: продаться (сумма сделки), стать корпорацией, закрыться легендой.
  Банкротство как исход без оценки.
- Случайный старт: один жанр и одна технология из пула, фиксированный бюджет с запасом над
  самой дорогой парой. Первый релиз на выданной паре без конструктора, подсказки в мини-играх.
  Остальные жанры и технологии приходят через предложения прокачки и вставки.
- Между забегами: галерея игр с переигрыванием демок, лучшие концовки, открытые сеттинги.
  Остальное открыто, силы нет.

## Данные

- Сигналы: `run_finished(ending: EndingDef, score: int)`.
- Состояние: `RunState` — номер релиза, список `GameRecord`; `Profile` — галерея, концовки,
  открытые сеттинги.
- Тюнинг: `res://resources/run.tres` — кап, пороги концовок, стартовый бюджет, пул стартовых
  жанров и технологий.

## Крайние случаи и вне скоупа

- Кап достигнут без выбранной концовки: правило открыто.
- Сеттинги на старте: все открытые или один случайный. Открыто в GDD.
- Стартовая пара не повторяется два забега подряд (дёшево, стоит сделать).
- Вне скоупа: мета-сила между забегами, сохранение посреди забега (решить при реализации).
