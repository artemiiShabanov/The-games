# The-games

This is like The movies but The games. On Godot engine.

The Movies, только про игры: симулятор студии, где в собранную по параметрам игру можно реально поиграть перед выпуском

Godot 4.4. Проект Godot лежит в `thegames/`: открыть `thegames/project.godot` в редакторе, запуск F5.
